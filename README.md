# Excel & Power BI Practice Course — 20 Real-World Datasets

A hands-on portfolio lab: **20 real datasets (173 rows → 541,909 rows)**, each with a click-by-click practice guide that takes you from raw messy data to a finished Power BI dashboard — every number in every guide verified against the actual data.

## 🚀 How to start (1 minute)

1. On this GitHub page, click the green **`<> Code`** button → **Download ZIP**.
2. Unzip it anywhere.
3. Open **`datasets/index.html`** in your browser — that's the Practice Hub with all 20 sets.
4. Click any set, read its **⚡ Quick info** bar (time, prerequisites, data-file link), and follow the guide.

No installs beyond the two tools below; everything works offline (guides are self-contained HTML — no internet needed once downloaded).

## 🧰 What you need

| Tool | Where | Notes |
|------|-------|-------|
| **Excel 2016 or newer** | Already on most computers | Microsoft 365 recommended; guide 17's XLOOKUP needs 365/2021+ (an INDEX/MATCH fallback is included) |
| **Power BI Desktop** (free) | https://aka.ms/pbidesktop | Needed for the Phase B / DAX / dashboard halves of each guide |

## 📂 What's in each folder

```
datasets/
  NN-name/
    guide.html        ← the step-by-step practice guide (open in a browser)
    data/             ← the raw dataset(s) for that set
    SOURCE.txt        ← where the data came from
```

- **Guides 01–05** · Beginner foundations: KPI cards, bar/line/waterfall/scatter, maps
- **Guides 06–10** · Dirty data: semicolon CSVs, double `.xls` headers, −200 IoT sentinels, funnels & gauges
- **Guides 11–15** · Multi-table & scale: bridge tables, folder combine, 542k-row ERP, small multiples
- **Guides 16–20** · Advanced/capstone: unpivot, Key Influencers AI, PL-300 star schema, field parameters, What-If, RLS

⏱ **Total course time ≈ 30–35 hours.** Each guide shows its own estimate and prerequisites at the top.

## 📖 Stuck on a word?

Open **`datasets/glossary.html`** — every term (CSV, PivotTable, star schema, DIVIDE, filter context, …) in plain English.

## ✅ Quality guarantees

- Every check figure in every guide was re-computed from the actual data files.
- Every formula step tells you what the cell will actually display (Excel auto-formats can look like errors).
- Guides are self-contained: no CDN, no fonts, no images to download — perfect for classrooms with no internet.
