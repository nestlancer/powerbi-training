Three Real-World Banking Traps Inside default of credit card clients.xls:
1. The Double-Header Row Trap: Row 1 contains research variable tags ('', 'X1', 'X2', ..., 'X23', 'Y'), while Row 2 holds the real column names (ID, LIMIT_BAL, ..., default payment next month)! Until Row 1 is deleted, every number is forced into Text!
2. Undocumented Codes in EDUCATION & MARRIAGE: Official codes are 1 = Graduate School, 2 = University, 3 = High School, 4 = Others — yet the raw file also contains 0, 5, 6! Consolidate 0, 4, 5, 6 → "4. Other" (468 clients) so charts stay clean.
3. Six Monthly Columns Are Snapshots, NOT Additive Revenue: BILL_AMT1..6 are statement balances from Sep back to Apr. Summing all 6 bills multiplies a revolving balance 6×! Use BILL_AMT1 (latest statement, avg NT$51,223) against LIMIT_BAL (avg NT$167,484) to measure Credit Utilization (30.58%).

4. Phase A — Step-by-Step in Microsoft Excel

Step A1 — Open .xls & Delete the Dummy X1..Y Row

  1. Open datasets/07-credit-clients/data/default of credit card clients.xls in Excel (sheet name: Data).
  2. Look at Row 1: B1 = X1, C1 = X2, …, Y1 = Y. Look at Row 2: A2 = ID, B2 = LIMIT_BAL, …, Y2 = default payment next month!
  3. Right-click row number 1 on the far left → click Delete. Now Row 1 has your clean headers and Rows 2–30,001 hold all 30,000 clients!
  4. Click View → Freeze Panes → Freeze Top Row.

Step A2 — Add 3 Helper Columns (Columns Z, AA, AB)

  1. Column Z — EduLabel: =IF(D2=1,"1. Graduate School",IF(D2=2,"2. University",IF(D2=3,"3. High School","4. Other")))
  2. Column AA — DelinquencyTier (from PAY_0 in G2): =IF(G2<=0,"1. Current / Revolving",IF(G2=1,"2. 1 Month Late","3. 2+ Months Late"))
  3. Column AB — LimitBand (from LIMIT_BAL in B2): =IF(B2<=50000,"1. <=50K",IF(B2<=150000,"2. 51K-150K",IF(B2<=300000,"3. 151K-300K","4. >300K")))

Step A3 — PivotTable Check

Insert a PivotTable: Rows = DelinquencyTier, Columns = LimitBand, Values = Average of default payment next month (formatted as 0.0%). Confirm overall Grand Total = 22.1% (22.12%), 3. 2+ Months Late = 69.6%, and Save As 07-credit-clients-clean.xlsx (saving as modern .xlsx is also much faster for Power BI than legacy 97–2003 .xls!).

5. Phase B — Complete Power BI & Charts Journey

Stage 1 & 2 — Clean Headers & Risk Tiers in Power Query

  1. Connect to your saved 07-credit-clients-clean.xlsx (or raw .xls) → tick Data → click Transform Data. Rename query to Clients.
  2. If connecting to the raw .xls: Power Query promoted X1..Y as headers, leaving ID, LIMIT_BAL... in Row 1! Simply click Home → Use First Row as Headers one more time, then select all 25 columns (Ctrl+A) and click Transform → Detect Data Type! Verify all 25 columns are 123 (Whole Number).
  3. Rename column default payment next month to DefaultFlag (much cleaner to type in DAX!).
  4. Add Conditional Columns (if not already in your Excel file):
    • EducationLabel: 1 → 1. Graduate School · 2 → 2. University · 3 → 3. High School · Else → 4. Other.
    • DelinquencyTier: PAY_0 <= 0 → 1. Current / Revolving · PAY_0 = 1 → 2. 1 Month Late · Else → 3. 2+ Months Late.
    • LimitBand: LIMIT_BAL <= 50000 → 1. <=50K · <= 150000 → 2. 51K-150K · <= 300000 → 3. 151K-300K · Else → 4. >300K.
    • GenderLabel: SEX = 1 → Male · Else → Female.
  5. Click Home → Close & Apply.

Stage 3 & 4 — Model Hygiene & Credit-Risk DAX Measures

Set ID, SEX, EDUCATION, MARRIAGE, and PAY_0..PAY_6 Summarization = Don't summarize (or hide raw code columns!). Then create these measures: 
Total Clients = COUNTROWS ( 'Clients' )
// Check: 30,000

Defaulted Clients = SUM ( 'Clients'[DefaultFlag] )
// Check: 6,636

Default Rate % = DIVIDE ( [Defaulted Clients], [Total Clients], 0 )
// Format: 0.00% -> Check: 22.12%

Risk Ceiling % = 0.20
// 20.0% CRO risk threshold

Avg Credit Limit = AVERAGE ( 'Clients'[LIMIT_BAL] )
// Format: $#,0 -> Check: $167,484 (NT$)

Credit Utilization % =
DIVIDE ( SUM ( 'Clients'[BILL_AMT1] ), SUM ( 'Clients'[LIMIT_BAL] ), 0 )
// Format: 0.0% -> Check: 30.6% (30.58%)

Severe Delinquent Clients = CALCULATE ( [Total Clients], 'Clients'[PAY_0] >= 2 )
// Check: 3,130 high-risk accounts (69.55% default rate!)

8. Trainer's Troubleshooting: Common Beginner Mistakes

Mistake 1 — Columns are named X1, X2, ..., Y and everything is Text: You forgot to promote Row 2 as headers! Click Use First Row as Headers in Power Query and re-detect data types.
Mistake 2 — Summing EDUCATION or BILL_AMT1..6: Summing numeric category codes or summing 6 monthly balance snapshots creates fake totals. Always check what each column represents in the business world!
