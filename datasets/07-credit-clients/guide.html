4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Open the .xls file. The first row may be a title. If the headers are in row 2, delete the title row or use it as the header before you build a pivot.
Formats: EDUCATION → Number; SEX → Number; MARRIAGE → Number; default payment next month → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • Confirm the default flag is 0/1, not text.
  • Education and sex are codes. Write down the legend from the source note (1 = graduate school, and so on) and replace the codes or leave a note on the visual.
  • BILL_AMT and PAY_AMT columns repeat for six months. Do not sum all six into one 'total bill' unless the client asked for that — it mixes months.

Step 3 — No extra formula required

The columns you need are already on the sheet. Use the pivot in the next step to prove the totals before you leave Excel.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = EDUCATION. Values = Average of default payment next month. The grand total must be 22.1%. Format the value as Percentage. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 07-credit-clients-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Excel. If Power Query promotes the title row, use Use First Row as Headers once, or remove the title row first.

Step 2 — Power Query

Rename the main query to Clients. Set the types from Step 1. Watch Applied Steps. Then Close & Apply.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

defaultpaymentnextmonth = AVERAGE('Clients'[default payment next month])
Row Count = COUNTROWS('Clients')
EDUCATION = SUM('Clients'[EDUCATION])
Filtered rows = CALCULATE([Row Count], 'Clients'[SEX] = <one of the two values>)

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis EDUCATION, value the main measure.
  • A slicer for each small category (SEX, default payment next month, MARRIAGE).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

6. Sign-off

  • ☐ Row count is 30,000 after the cleaning steps above.
  • ☐ Average default payment next month is 22.1%.
  • ☐ The leading EDUCATION is 3 at 25.2%.
  • ☐ Slicers filter every visual, and you can clear them back to the totals above.

7. Stretch

  • A small multiples view of default rate by limit-balance band. Build the band with a nested IF or with Power BI grouping.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Summing six months of bill amounts and calling it the balance.
  • A default rate made by averaging the 0/1 column inside a bad total.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
