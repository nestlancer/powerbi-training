4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Data → From Text/CSV → netflix_titles.csv. date_added should become a date. duration is text ('90 min', '2 Seasons') — do not set it to a number.
Formats: date_added → Date. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • country can list several countries in one cell. A simple count will credit the whole string, not each country. Splitting is a stretch task.
  • director and cast are blank on many TV shows.
  • type has two values: Movie and TV Show.

Step 3 — Helper columns

Put these in the first empty columns and fill down (double-click the fill handle).
Year   =YEAR(G2)
MonthNum   =MONTH(G2)
MonthName   =TEXT(G2,"MMM")
Excel on this machine uses a comma between arguments. If your Excel uses semicolons, swap them.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = rating. Put release_year in Columns. Values = Sum of a Count of any text column. The grand total must be 7,787 rows. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 11-netflix-titles-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Text/CSV. Split duration into a number and a unit only if you need to compare movie length. Leave it as text until then.

Step 2 — Power Query

Rename the main query to Titles. Set the types from Step 1. Watch Applied Steps. Then Close & Apply.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

Row Count = COUNTROWS('Titles')
Filtered rows = CALCULATE([Row Count], 'Titles'[type] = <one of the two values>)

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis rating, value the main measure.
  • Line chart: axis date_added.
  • A slicer for each small category (type, rating).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

6. Sign-off

  • ☐ Row count is 7,787 after the cleaning steps above.
  • ☐ The leading rating is TV-MA at 2,863.
  • ☐ The date axis runs from 2008-01-01 to 2021-01-16.
  • ☐ Slicers filter every visual, and you can clear them back to the totals above.

7. Stretch

  • Split the country column on commas and count titles per country. Expect more title-country rows than titles.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Treating duration as a number while it still contains the word 'min'.
  • Using release_year and date_added as if they were the same event.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
