Three Real-World Dirty-Text Traps in netflix_titles.csv:
1. 88 Leading Spaces in date_added: Rows like " August 14, 2020" begin with a space! Always run Transform → Format → Trim BEFORE parsing as a Date (English - United States locale).
2. Mixed Units in duration: Column J stores both "90 min" (for Movies) and "4 Seasons" (for TV Shows). Split by space into DurationNum + DurationUnit and filter by type before averaging!
3. Comma-Separated Multi-Value Genres (listed_in): A single title has up to 3 genres (e.g., "International Movies, Dramas, Comedies"). Splitting into rows inside a 2-column TitleGenres bridge table lets you rank true individual genres (International Movies = 2,437, Dramas = 2,106)!

4. Phase A — Step-by-Step in Microsoft Excel

Step A1 — Import UTF-8 CSV & Add Clean Helper Columns

Open Excel → Data → From Text/CSV → select datasets/11-netflix-titles/data/netflix_titles.csv → File Origin: 65001: Unicode (UTF-8) (so international titles like João Miguel render cleanly!) → Load. Add helper columns: 
// Col M (YearAdded) — trims leading space and extracts 4-digit year:
=IF(G2="","", VALUE(RIGHT(TRIM(G2), 4)))

// Col N (PrimaryCountry) — text before first comma, or "Unknown":
=IF(F2="","Unknown", IFERROR(LEFT(F2, FIND(",",F2)-1), F2))

// Col O (DurationNum) — integer before first space:
=VALUE(LEFT(J2, FIND(" ", J2)-1))

Step A2 — Verify Key Catalog Stats in Excel

  • =COUNTIF(B2:B7788,"Movie") → 5,377 (69.05%) | TV Show → 2,410 (30.95%)
  • =AVERAGEIF(B2:B7788,"Movie",O2:O7788) → 99.3 minutes
  • =AVERAGEIF(B2:B7788,"TV Show",O2:O7788) → 1.78 seasons
Save as 11-netflix-clean.xlsx.

5. Phase B — Complete Power BI & Charts Journey

Stage 1 & 2 — Clean Titles + Build TitleGenres Bridge Table in Power Query

  1. Click Home → Text/CSV → select data/netflix_titles.csv (UTF-8) → Transform Data. Rename query to Titles.
  2. Fix date_added: Select date_added → Transform → Format → Trim → right-click header → Change Type → Using Locale → Data Type: Date, Locale: English (United States). Then click Add Column → Date → Year → Year (name: YearAdded).
  3. Extract PrimaryCountry: Replace blank/empty values in country with Unknown → click Add Column → Extract → Text Before Delimiter → Delimiter: , → rename to PrimaryCountry.
  4. Split duration: Select duration → Transform → Split Column → By Delimiter → Space (Left-most delimiter) → rename to DurationNum (Whole Number) and DurationUnit.
  5. Build the Exploded Genre Bridge Table (Pro BI Technique!):
    • In the left Queries pane, right-click Titles → click Reference → rename the new query to TitleGenres.
    • Hold Ctrl and click show_id and listed_in → right-click → Remove Other Columns.
    • Select listed_in → Transform → Split Column → By Delimiter → Delimiter: Comma → expand Advanced options → choose Rows (NOT Columns!) → click OK!
    • Click Transform → Format → Trim on listed_in and rename it to Genre.
  6. Click Home → Close & Apply.

Stage 3 — Connect Titles (1) → (*) TitleGenres in Model View

Open Model view: confirm Titles[show_id] (1) connects to TitleGenres[show_id] (*), Single cross-filter direction (or Both if you want clicking a Genre bar to filter Country/Trend charts — since Titles is the only fact table here, setting Cross-filter direction = Both on this 2-table model lets clicking Dramas slice every visual on the page!).

Stage 4 — DAX Measures

Total Titles = DISTINCTCOUNT ( 'Titles'[show_id] )
// Check: 7,787 (safe even when sliced by TitleGenres!)

Movie Count = CALCULATE ( [Total Titles], 'Titles'[type] = "Movie" )
// Check: 5,377

TV Show Count = CALCULATE ( [Total Titles], 'Titles'[type] = "TV Show" )
// Check: 2,410

Movie Share % = DIVIDE ( [Movie Count], [Total Titles] )
// Check: 69.1%

Avg Movie Runtime (min) =
CALCULATE ( AVERAGE ( 'Titles'[DurationNum] ), 'Titles'[type] = "Movie" )
// Check: 99.3

One-Season TV Rate % =
VAR OneS = CALCULATE ( [TV Show Count], 'Titles'[DurationNum] = 1 )
RETURN DIVIDE ( OneS, [TV Show Count] )
// Check: 66.7% (1,608 of 2,410 TV Shows!)

8. Trainer's Troubleshooting: Common Beginner Mistakes

Mistake 1 — Splitting listed_in into Columns instead of Rows: Splitting into Genre.1, Genre.2, Genre.3 makes it impossible to build a single clean Genre Bar Chart! Always split into Rows inside a separate Bridge Table.
Mistake 2 — Counting rows of TitleGenres for Total Titles: That returns ~17,071 genre tags instead of 7,787 titles! Always use DISTINCTCOUNT('Titles'[show_id]).
