2. The client brief

The ask: We sell into several countries and segments. I need to see which country and which product actually make profit, and whether discounts are eating it.

4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Open Financial-Sample.xlsx. If the Sales header has a leading space, rename it to Sales.
Formats: Date → Date; Gross Sales → Number (2 decimals); Sales → Number (2 decimals); COGS → Number (2 decimals); Profit → Number (2 decimals). Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • Turn on Filter and look for blank Product or Country rows.
  • Discount Band is text (None, Low, Medium, High), not a number.
  • Confirm Sales and Profit are numbers, not text.

Step 3 — No extra formula required

The columns you need are already on the sheet. Use the pivot in the next step to prove the totals before you leave Excel.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = Country. Put Year in Columns. Values = Sum of Profit. The grand total must be $16.89M. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 01-financial-sample-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Excel → this workbook → the financial sheet → Transform.

Step 2 — Power Query

Rename the main query to Financials. Set the types from Step 1. Watch Applied Steps. Then Close & Apply.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

Profit = SUM('Financials'[Profit])
Row Count = COUNTROWS('Financials')
GrossSales = SUM('Financials'[Gross Sales])
Margin % = DIVIDE([Profit], [GrossSales])
Filtered rows = CALCULATE([Row Count], 'Financials'[Year] = <one of the two values>)

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis Country, value the main measure.
  • Line chart: axis Date.
  • A slicer for each small category (Discount Band, Segment, Country).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

6. Sign-off

  • ☐ Row count is 700 after the cleaning steps above.
  • ☐ Total Profit is $16.89M.
  • ☐ The leading Country is France at $3.78M.
  • ☐ The date axis runs from 2013-09-01 to 2014-12-01.
  • ☐ Slicers filter every visual, and you can clear them back to the totals above.

7. Stretch

  • A what-if parameter that cuts Profit by an extra discount on one segment.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Treating Discount Band as a number you can average.
  • Building the report on Gross Sales when the client asked about Profit.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
