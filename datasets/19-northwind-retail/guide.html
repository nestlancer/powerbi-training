4. Phase A — Organize & Clean in Microsoft Excel

Goal: understand + tidy the data, add helper columns, validate with a Pivot, then hand a clean .xlsx to Power BI.

Step 1 — Open correctly

Open the file: data/retail_sales_2021_2024.csv, in the folder next to this guide (Excel auto-splits columns by comma). For full control of types use Data ▸ Get Data ▸ From Text/CSV → choose the file → set Delimiter = Comma → Load.
Set formats: select OrderDate, ShipDate → Home ▸ Number ▸ Date; Sales, Profit, Discount → Number with 2 decimals; everything else stays Text. Then View ▸ Freeze Panes ▸ Freeze Top Row.

Step 2 — Inspect for dirt (trainer habit)

The file is clean, but on a real client file do: Data ▸ Filter → check Discount > 0.8, Profit blank, or future OrderDate. Use Data ▸ Remove Duplicates on OrderID.

Step 3 — Add helper columns (columns T–Y, after Profit in S)

T Year   =YEAR(B2)
U MonthNum   =MONTH(B2)
V MonthName   =TEXT(B2,"MMM")  (Excel uses , as the argument separator, as shown. If your regional setting uses ;, swap commas for semicolons.)
W Quarter   ="Q"&ROUNDUP(MONTH(B2)/3,1)
X ProfitMargin   =IF(N2=0,0,Q2/N2) → format Percent
Y LossFlag   =IF(Q2<0,"LOSS","OK")
Fill down (double-click the small square at the cell's bottom-right).

Step 4 — Validate with a PivotTable

Select all data → Insert ▸ PivotTable. Rows = Category, Columns = Year, Values = Sum of Profit. Confirm Technology ≈ +$31.7M, Furniture ≈ −$13.3M (matches §1). This is your sanity check.

Step 5 — Format & export

Sales/Profit → #,##0.00; Discount/Margin → 0.0%.
Save As retail_sales_clean.xlsx — keep this as your working copy; Power BI reads the typed Excel file most reliably (better than the raw CSV).

5. Phase B — Build the Dashboard in Power BI

Step 1 — Get Data

Get Data ▸ Excel → retail_sales_clean.xlsx → Load. (Or Text/CSV → comma → Transform → Load.)

Step 2 — Power Query (trust the types)

Transform Data: OrderDate/ShipDate = Date; Sales/Profit/Discount = Decimal; Year/MonthNum = Whole Number. If a column is Text, change type and watch Applied Steps (you can undo any). Close & Apply.

Step 3 — Data Modeling (the "BI")

Create a Date table (enables time intelligence):
Calendar = CALENDAR(DATE(2021,1,1), DATE(2024,12,31))
Add Calendar[Year]=YEAR([Date]), Calendar[Month]=FORMAT([Date],"MMM"), Calendar[MonthNo]=MONTH([Date]), Calendar[Quarter]="Q"&ROUNDUP(MONTH([Date])/3,0).
Draw relationship: Calendar[Date] → retail_sales[OrderDate]. Hide the row-level Year/Quarter to avoid confusion.

Step 4 — DAX Measures (write as measures, NOT columns)

Total Sales     = SUM(retail_sales[Sales])
Total Profit    = SUM(retail_sales[Profit])
Order Count     = DISTINCTCOUNT(retail_sales[OrderID])
Avg Discount    = AVERAGE(retail_sales[Discount])
Profit Margin % = DIVIDE([Total Profit], [Total Sales])   -- ≈ 2.7% overall
Avg Order Value = DIVIDE([Total Sales], [Order Count])

Sales YoY % =
VAR PY = CALCULATE([Total Sales], SAMEPERIODLASTYEAR('Calendar'[Date]))
RETURN DIVIDE([Total Sales] - PY, PY)

Sales Running Total =
CALCULATE([Total Sales],
    FILTER(ALL('Calendar'), 'Calendar'[Date] <= MAX('Calendar'[Date])))

Loss Lines = CALCULATE(COUNTROWS(retail_sales), retail_sales[LossFlag]="LOSS")

Modeling ▸ New Parameter ▸ Numeric → Discount Cap (0 to 0.8, step 0.05). New measure:

8. Trainer's Common Mistakes

  • Importing CSV with dates as Text → no time intelligence. Fix types in Power Query.
  • Forgetting the Date-table relationship → SAMEPERIODLASTYEAR returns blank.
  • Putting calculations in columns instead of measures → totals break.
  • Averaging a percentage column directly → wrong. Use DIVIDE(SUM(Profit), SUM(Sales)).
