4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Data → From Text/CSV → chicago-salaries.csv. Annual Salary may arrive as text with commas. Convert it to a number.
Formats: Annual Salary → Number (2 decimals); Typical Hours → Number; Hourly Rate → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • Do not delete blank Annual Salary rows. Check Salary or Hourly first.
  • Name is an identifier. The report groups by Department and Job Titles.
  • Typical Hours is the scheduled week, not overtime.

Step 3 — No extra formula required

The columns you need are already on the sheet. Use the pivot in the next step to prove the totals before you leave Excel.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = Department. Values = Sum of Annual Salary. The grand total must be $2.88B. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 08-chicago-payroll-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Text/CSV. Replace a leading $ or commas, then set Annual Salary and Hourly Rate to decimal.

Step 2 — Power Query

Rename the main query to Payroll. Set the types from Step 1. Watch Applied Steps. Then Close & Apply.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

AnnualSalary = SUM('Payroll'[Annual Salary])
Row Count = COUNTROWS('Payroll')
TypicalHours = SUM('Payroll'[Typical Hours])
Filtered rows = CALCULATE([Row Count], 'Payroll'[Full or Part-Time] = <one of the two values>)

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis Department, value the main measure.
  • A slicer for each small category (Full or Part-Time, Salary or Hourly, Typical Hours).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

6. Sign-off

  • ☐ Row count is 32,226 after the cleaning steps above.
  • ☐ Total Annual Salary is $2.88B.
  • ☐ The leading Department is CHICAGO POLICE DEPARTMENT at $1.44B.
  • ☐ Slicers filter every visual, and you can clear them back to the totals above.

7. Stretch

  • Headcount and total annual salary on one bar chart, with a slicer for Full or Part-Time.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Summing Hourly Rate as if it were annual pay.
  • A pivot that drops hourly staff because Annual Salary is blank.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
