TermPlain-English meaning
Files & Data Basics
CSVComma-Separated Values — a plain-text table where commas separate columns. Opens in any tool; no formatting, just data.
DelimiterThe character splitting columns in a text file — comma, semicolon (guide 06), or tab. Wrong delimiter = one giant column.
XLSXAn Excel workbook file. Can store multiple sheets, formats, and formulas — unlike CSV.
Workbook / WorksheetThe whole Excel file (workbook) vs. one tab inside it (worksheet/sheet).
Header rowRow 1 containing column names. Some files hide a second "tag" row under it (guide 07's double-header trap).
GranularityWhat one row represents — one day (guide 05), one invoice line (guide 14), one person (guide 20). Mixing granularities double-counts.
Sentinel valueA fake number standing in for "missing" — e.g. −200 for dead sensors (guide 10), −1 for "never contacted" (guide 06), \N (guide 12).
Null / BlankAn empty cell — "no value recorded". Different from 0! Averages skip blanks but include zeros.
Data dictionaryA table listing every column and what it stores. Build one before analyzing any new file.
ISO / ISO-3 codeStandard 2–3 letter country codes (IND, USA). Blank codes in guide 16 = aggregate rows, not countries.
Excel Formulas
Cell referenceA cell's address, like J2 (column J, row 2).
Relative vs. absolute ($)A1 shifts when you copy the formula; $A$1 stays locked on that cell. $ = "don't move".
Excel Table (structured refs)Ctrl+T converts a range to a smart Table. Formulas then read [@[Net Sales]] ("this row's Net Sales") and auto-fill down.
IF(condition, then, else)If the condition is true do the first thing, otherwise the second. Nested IFs chain multiple rules.
IFERROR / ISBLANKIFERROR replaces an error with a value you choose; ISBLANK tests for truly empty cells (guide 04's blank-vs-0 trap).
VLOOKUP / XLOOKUPFind a value in one column and return a value from another. XLOOKUP (Microsoft 365/2021+ only) is safer and easier; older Excel uses INDEX/MATCH.
COUNTIF / AVERAGEIF / SUMIFSCount / average / sum rows that meet a condition — your first "analytics" functions.
PROPER / TRIM / LEFT / MIDText cleaners: fix ALL CAPS, strip stray spaces, slice characters out of strings.
DATE / DATEVALUEBuild a real date from parts (DATE(Y,M,D)) or convert a text date into a real one. Excel stores dates as serial numbers.
Error codes#NAME? misspelled name · #DIV/0! divide by zero/blank · #N/A not found · #VALUE! text in a math formula · #REF! deleted referenced cells.
Fill handle / Ctrl+DDrag the little square at a cell's corner (or press Ctrl+D) to copy a formula down thousands of rows.
PivotTables & Chart Basics
PivotTableDrag-and-drop summary: Rows = groups, Values = numbers (Sum/Count/Average), Columns = split, Filters = restrict.
"Sum of" fieldDefault Value naming ("Sum of Profit"). Rename to a real label — future-you will thank you.
% of TotalRight-click a pivot value → Show Values As → % of Grand Total, for share-of-whole analysis.
SlicerClickable filter buttons attached to a pivot/chart — one click filters everything connected.
Axis / Legend / Data fieldThe three drag zones of a chart: what's along the bottom, what each color means, what the bars measure.
Choropleth (filled map)A map colored by value — needs country/city names or codes Power BI can place.
Power Query (Excel & Power BI's data cleaner)
Power QueryThe data-prep engine built into Excel and Power BI: point it at files, clean step by step, refresh later with one click.
Applied StepsThe recorded list of your cleaning actions on the right — each is repeatable and editable.
Promote HeadersTell Power Query "row 1 is column names", not data.
Change TypeMark each column as Number / Date / Text. Wrong types silently break sorts, math, and date logic.
Replace Values / Replace ErrorsSwap sentinels (−200) for nulls, or clean error cells, inside the query.
Split ColumnBreak one column into several by a delimiter — "99 min" → 99 + "min" (guide 11).
UnpivotFlip wide columns (year 1750…2025) into two tidy columns (Year, Value) — the fix for guide 16's 79-column sheet.
Append (Combine Files)Stack many files/tables with the same columns into one — guide 13's 12 monthly CSVs become one table.
MergeJoin two tables on a shared key — like VLOOKUP, but in Power Query, and it keeps both tables intact.
Folder combinePoint Power Query at a folder (not a file); new files dropped in are included on refresh.
Close & LoadPush the cleaned query result back to an Excel sheet (or the Data Model).
Data Modeling
Star schemaOne central fact table (sales rows) connected to dimension tables (Product, Customer, Date) by keys. The professional layout Power BI loves.
Fact tableThe big table of events/transactions — one row per sale, booking, or ticket (guides 18–20: 121k–220k rows).
Dimension tableThe smaller "lookup" tables describing things: products, customers, dates, roles.
Primary / Foreign keyThe ID that identifies a row (ProductKey in Product) vs. the same ID repeated in the fact table to link rows.
Relationship cardinalityOne-to-many (normal), one-to-one (rare), many-to-many (dangerous — guide 17). Always aim for one-to-many from dimension to fact.
SnowflakeDimensions split into sub-dimensions (guide 17's 7 sheets). Flatten or model carefully — cross-filtering gets confusing.
Role-playing tableOne Date table used several ways (order date, ship date). Only one relationship is active; measures activate others with USERELATIONSHIP.
Bridge tableA helper table resolving many-to-many — one row per title-and-genre pair (guide 11).
Row-Level Security (RLS)Rules so each viewer only sees their own slice of data (guide 20's region managers).
DAX (Power BI's formula language)
Measure vs. calculated columnA measure computes on the fly per visual (use 95% of the time); a calculated column stores a value per row (rare).
Filter contextThe filters currently applying to a calculation (slicer + row + cross-highlight). Measures re-run for every context.
SUM / AVERAGE / DISTINCTCOUNT / COUNTROWSBasic aggregations. DISTINCTCOUNT counts unique values — customers, not orders.
DIVIDE(a, b, alt)Safe division: returns alt (usually 0 or blank) instead of an error when b is 0. Always prefer DIVIDE over /.
CALCULATE(expr, filter)DAX's swiss knife: recompute an expression under new filters. E.g. CALCULATE([Sales], 'Product'[Category]="Bikes").
FILTER / ALL / ALLSELECTEDTable filters: FILTER picks rows, ALL clears filters (denominator for % of total), ALLSELECTED respects the slicer.
SUMX / iterators (X-functions)Row-by-row computation then aggregation — e.g. quantity × price per row, then sum.
VAR … RETURNStore intermediate results in variables for readable, fast formulas.
SAMEPERIODLASTYEAR / DATESYTD / TOTALYTDTime intelligence: last year's value, year-to-date — needs a proper Date table and continuous dates.
Date tableA dedicated table of continuous dates (one row per day) marked as the model's official calendar. Required for YoY/YTD.
USERELATIONSHIPTemporarily activate an inactive relationship inside one measure (ship-date analysis in guides 12 & 18).
(Blank) in DAXMeans "no rows matched the filters" — often a relationship or filter mismatch, not zero.
Business Metrics Used in the Guides
Margin %Profit ÷ Sales. Guide 01: 14.23%; guide 19: 2.66% (thin!).
YoY (Year-over-Year)This year vs. same period last year — the core growth metric.
YTD / Fiscal YTDRunning total since Jan 1 (or the fiscal start — Adventure Works' July 1).
AOVAverage Order Value = revenue ÷ number of orders (guide 13: $193.30).
ADRAverage Daily Rate for a hotel booking (guide 15) — the per-night price.
Pareto (80/20)The top ~20% of customers drive ~80% of revenue — computed with a cumulative % measure (guide 14).
Conversion rateShare of contacts/clicks that became customers (guides 06, 18).
Attrition / ChurnShare of employees (guide 20) or customers who left during the period.
CSAT / SLACustomer Satisfaction rating (High/Medium/Low) and the promised resolution deadline (guide 17: under 4 days).
What-If parameterA slider-backed number (discount cap, replacement cost %) that live-recalculates measures — great for scenario demos.
Field parametersLet report viewers switch the metric/axis themselves from a slicer (guide 19's dynamic metric switcher).
Drill-throughRight-click a chart bar → jump to a detail page filtered to that item (guides 19–20).
Small multiplesOne chart template repeated per group (hotel type, region) for easy comparison (guide 15).
