4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Data → From Text/CSV → recent-grads.csv → comma → Load.
Formats: P75th → Number; Total → Number; Employed → Number; P25th → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • 173 majors. That is the whole file — do not expect a time axis.
  • ShareWomen and Unemployment_rate are fractions (0.25 means 25%). Format them as %.
  • Rank is not a measure. Do not sum it.

Step 3 — No extra formula required

The columns you need are already on the sheet. Use the pivot in the next step to prove the totals before you leave Excel.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = Major_category. Values = Average of Median. The grand total must be $40,151. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 02-college-majors-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Text/CSV → comma → Transform.

Step 2 — Power Query

Rename the main query to Majors. Set the types from Step 1. Watch Applied Steps. Then Close & Apply.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

Median = AVERAGE('Majors'[Median])
Row Count = COUNTROWS('Majors')
P75th = SUM('Majors'[P75th])

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis Major_category, value the main measure.
  • A slicer for each small category (Major_category).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

7. Stretch

  • A scatter of Median earnings (X) against Unemployment_rate (Y), with Major_category as the legend.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Averaging Unemployment_rate across a category as if every major had the same number of graduates.
  • Using Total (graduate count) as if it were dollars.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
