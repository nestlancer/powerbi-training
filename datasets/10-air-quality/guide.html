4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Open AirQualityUCI.xlsx. Date and Time are separate. The sensor columns use a comma as the decimal mark in the CSV twin — the workbook is the easier file.
Formats: Date → Date; PT08.S4(NO2) → Number; PT08.S1(CO) → Number; PT08.S5(O3) → Number; PT08.S2(NMHC) → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • Replace -200 with blank on every sensor column before any average.
  • Do not sum hourly readings and call it a daily total unless you mean a sum. The client asked for a pattern, so average by hour.
  • NMHC(GT) is mostly missing. Do not build the main visual on it.

Step 3 — Helper columns

Put these in the first empty columns and fill down (double-click the fill handle).
Year   =YEAR(A2)
MonthNum   =MONTH(A2)
MonthName   =TEXT(A2,"MMM")
Excel on this machine uses a comma between arguments. If your Excel uses semicolons, swap them.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = Time. Group the date by years and put years in Columns. Values = Average of CO(GT). The grand total must be 2.15 mg/m³. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 10-air-quality-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Excel → the air-quality sheet. Replace -200 with null on the sensor columns.

Step 2 — Power Query

Rename the main query to AirQuality. Set the types from Step 1. Watch Applied Steps. Then Close & Apply.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

CO = AVERAGE('AirQuality'[CO(GT)])
NO2 = AVERAGE('AirQuality'[NO2(GT)])
Row Count = COUNTROWS('AirQuality')

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis Time, value the main measure.
  • Line chart: axis Date.
  • A slicer for each small category (Time).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

6. Sign-off

  • ☐ Row count is 9,357 after the cleaning steps above.
  • ☐ Average CO(GT) is 2.15 mg/m³.
  • ☐ The leading Time is 19:00:00 at 3.73 mg/m³.
  • ☐ The date axis runs from 2004-03-10 to 2005-04-04.
  • ☐ Slicers filter every visual, and you can clear them back to the totals above.

7. Stretch

  • A line of CO(GT) by hour of day, averaged, with a second line for one sensor.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Averaging -200 as if it were a real reading.
  • A line chart of every sensor on one axis when the scales differ by orders of magnitude.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
