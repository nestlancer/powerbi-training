2. The client brief

Who: A foundation that briefs non-specialists on global development.

The ask: I need one view of life expectancy against income, over decades, and I need to slice it by continent. Do not add GDP per person across countries — that number is already 'per person'.

4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Data → From Text/CSV → gapminder.csv → comma → Load.
Formats: pop → Number; gdpPercap → Number; lifeExp → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • Confirm one row is one country-year, not one person.
  • lifeExp and gdpPercap should be averaged, not summed.
  • Population (pop) is the additive measure.

Step 3 — No extra formula required

The columns you need are already on the sheet. Use the pivot in the next step to prove the totals before you leave Excel.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = continent. Put year in Columns. Values = Average of lifeExp. The grand total must be 67 years. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 03-gapminder-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Text/CSV. Year is a number, not a date.

Step 2 — Power Query

Rename the main query to Gapminder. Set the types from Step 1. Watch Applied Steps. Then Close & Apply. Filter year to 2007 before you compare a card to the sign-off. Average lifeExp and gdpPercap. Sum pop.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

lifeExp = AVERAGE('Gapminder'[lifeExp])
Row Count = COUNTROWS('Gapminder')
pop = SUM('Gapminder'[pop])

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis continent, value the main measure.
  • Line chart: axis year.
  • A slicer for each small category (continent).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

6. Sign-off

  • ☐ Row count is 142 after the cleaning steps above.
  • ☐ Average lifeExp is 67 years.
  • ☐ The leading continent is Oceania at 80.7 years.
  • ☐ Slicers filter every visual, and you can clear them back to the totals above.

7. Stretch

  • A scatter of gdpPercap (X) and lifeExp (Y) with year as a play axis, or small multiples by continent.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Summing gdpPercap and calling it world GDP.
  • A line chart of every country at once. Filter to one continent first.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
