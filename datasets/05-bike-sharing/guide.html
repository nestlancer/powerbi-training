4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Excel: open day.csv only. Power BI: load hour.csv as the fact table. Leave day.csv out of the model.
Formats: cnt → Number; registered → Number; casual → Number; weathersit → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • season, weathersit, and weekday are codes, not labels. Keep a small lookup (1 = clear, and so on) or replace the values.
  • temp and hum are normalized (not degrees, not a percent in the 0–100 sense). Do not sum them.
  • cnt is the measure. instant is a row id.

Step 3 — No extra formula required

The columns you need are already on the sheet. Use the pivot in the next step to prove the totals before you leave Excel.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = season. Values = Sum of cnt. The grand total must be 3,292,679. If it is not, the filter or the number format is wrong — fix that before Power BI.
hour.csv has 17,379 rows and the same total rides if you sum cnt (3,292,679). Do not put both files in one model. The sign-off row count is day.csv.

Step 5 — Save

Save As 05-bike-sharing-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Text/CSV → hour.csv. dteday is a date. cnt is total rentals. casual + registered should equal cnt.

Step 2 — Power Query

Rename the main query to Trips. Set the types from Step 1. Watch Applied Steps. Then Close & Apply. Add a check column casual + registered - cnt. It should be 0. Then remove that check column.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

cnt = SUM('Trips'[cnt])
Row Count = COUNTROWS('Trips')
registered = SUM('Trips'[registered])
Filtered rows = CALCULATE([Row Count], 'Trips'[yr] = <one of the two values>)

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis season, value the main measure.
  • A slicer for each small category (yr, holiday, workingday).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

6. Sign-off

  • ☐ Row count is 731 after the cleaning steps above.
  • ☐ Total cnt is 3,292,679.
  • ☐ The leading season is 3 at 1,061,129.
  • ☐ Slicers filter every visual, and you can clear them back to the totals above.

7. Stretch

  • A line of cnt by hour, with a slicer for workingday, built on hour.csv.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Relating day.csv to hour.csv on dteday. One day matches many hours, and both tables already contain cnt, so totals double.
  • Summing the temperature column.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
