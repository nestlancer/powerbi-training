4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Data → From Text/CSV → hotels.csv. arrival_date_year, arrival_date_month, and arrival_date_day_of_month are separate. You can build a real date later; the month name is enough for the first chart.
Formats: reservation_status_date → Date; adr → Number (2 decimals); lead_time → Number; agent → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • children can be blank. Treat blank as 0 if you count guests.
  • reservation_status_date is a date. The arrival fields are parts, not a single date.
  • company and agent are ids and are often blank. Do not drop the row for that.

Step 3 — Helper columns

Put these in the first empty columns and fill down (double-click the fill handle).
Revenue   =IF(B2=0,AB2*(H2+I2),0)
Year   =YEAR(AF2)
MonthNum   =MONTH(AF2)
MonthName   =TEXT(AF2,"MMM")
Excel on this machine uses a comma between arguments. If your Excel uses semicolons, swap them.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = hotel. Put arrival_date_year in Columns. Values = Sum of Revenue. The grand total must be $26.00M. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 15-hotel-bookings-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Text/CSV. is_canceled is 0 or 1. adr is the daily rate.

Step 2 — Power Query

Rename the main query to Bookings. Set the types from Step 1. Watch Applied Steps. Then Close & Apply.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

Revenue = SUMX(FILTER('Bookings', 'Bookings'[is_canceled] = 0),
    'Bookings'[adr] * ('Bookings'[stays_in_weekend_nights] + 'Bookings'[stays_in_week_nights]))
Row Count = COUNTROWS('Bookings')
adr = AVERAGE('Bookings'[adr])
Filtered rows = CALCULATE([Row Count], 'Bookings'[hotel] = <one of the two values>)

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis hotel, value the main measure.
  • Line chart: axis reservation_status_date.
  • A slicer for each small category (hotel, is_canceled, is_repeated_guest).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

7. Stretch

8. Mistakes that hide the answer

  • Summing adr and calling it revenue.
  • Including cancelled stays in the revenue helper.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
