4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Data → From Text/CSV → population.csv. Rename Value to Population so the pivot is readable.
Formats: Population → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • Value is population, not a rate.
  • Country Name repeats once per year. A sum without a year filter is wrong.
  • Aggregates such as 'World' or 'Africa' may sit in the same column as countries. If a total looks twice too big, filter to country codes only.

Step 3 — No extra formula required

The columns you need are already on the sheet. Use the pivot in the next step to prove the totals before you leave Excel.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = Country Name. Put Year in Columns. Values = Sum of Population. The grand total must be 8,117,484,624. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 09-world-population-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Text/CSV. Rename Value to Population. Year stays a whole number.

Step 2 — Power Query

Rename the main query to Population. Set the types from Step 1. Watch Applied Steps. Then Close & Apply. Filter Year to 2024. Remove rows whose Country Code is an aggregate: AFE, AFW, ARB, CEB, CSS, EAP, EAR, EAS, ECA, ECS, EMU, EUU, HIC, HPC, IBD, IBT, IDA, IDB, IDX, LAC, LCN, LDC, LIC, LMC, LMY, LTE, MEA, MIC, MNA, NAC, OED, OSS, PRE, PSS, PST, SAS, SSA, SSF, SST, TEA, TEC, TLA, TMN, TSA, TSS, UMC, WLD. Rename Value to Population. The card is the sum of Population after that filter.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

Population = SUM('Population'[Population])
Row Count = COUNTROWS('Population')

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis Country Name, value the main measure.
  • Line chart: axis Year.
  • A slicer for each small category (any low-cardinality column).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

7. Stretch

  • A line of the ten largest countries in the latest year, with Year on the axis.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Summing every year into one number.
  • Adding 'World' on top of every country.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
