Practice sets · Excel then Power BI

Every practice file is in this folder. Each numbered folder is one dataset and one guide. The totals in the guide were computed from that folder's file. Start at 01 (a few hundred rows). 19 and 20 are the long case studies, about 220,000 rows each.

How to use a set: open guide.html → Phase A in Excel → Phase B in Power BI → tick the sign-off only when your total matches the guide. Sets 01–18 are public tables you can open directly. Sets 19 and 20 are the long generated case studies (about 220,000 rows each).
