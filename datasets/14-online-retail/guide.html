4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Open Online Retail.xlsx. If Excel is slow, do the pivot on a Table and do not scroll every row. Power BI is the better place for the full file.
Formats: InvoiceDate → Date; UnitPrice → Number (2 decimals); StockCode → Number; Quantity → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • Do not delete blank CustomerID rows.
  • Invoice numbers that start with C are cancellations. Quantity is negative on those rows.
  • UnitPrice can be zero. A helper LineSales = Quantity * UnitPrice is the revenue column.

Step 3 — Helper columns

Put these in the first empty columns and fill down (double-click the fill handle).
LineSales   =D2*F2
Year   =YEAR(E2)
MonthNum   =MONTH(E2)
MonthName   =TEXT(E2,"MMM")
Excel on this machine uses a comma between arguments. If your Excel uses semicolons, swap them.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = Country. Group the date by years and put years in Columns. Values = Sum of LineSales. The grand total must be $9.75M. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 14-online-retail-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Excel → the Online Retail sheet. InvoiceNo stays text so the leading C is kept.

Step 2 — Power Query

Rename the main query to Invoices. Set the types from Step 1. Watch Applied Steps. Then Close & Apply.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

Line Sales = SUMX('Invoices', 'Invoices'[Quantity] * 'Invoices'[UnitPrice])
Row Count = COUNTROWS('Invoices')
UnitPrice = SUM('Invoices'[UnitPrice])

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis Country, value the main measure.
  • Line chart: axis InvoiceDate.
  • A slicer for each small category (Country).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

7. Stretch

  • A ReturnFlag column, LEFT(InvoiceNo, 1) = "C", and a card for net LineSales versus the return lines only.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Setting InvoiceNo to a whole number and losing the letter C.
  • Dropping blank customers and then wondering why the total moved.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
