5. Phase B — Complete 3-Page Power BI People-Analytics Build

Stage 1 & 2 — Power Query Banding & Flight-Risk Flagging

  1. Import data/hr_workforce.csv → Transform Data → rename to Workforce.
  2. Set HireDate and TerminationDate = Date (blank TerminationDate becomes null cleanly for the 173,526 active staff!). Set MonthlyIncome & AnnualSalary = Currency ($), and survey/tenure fields = Whole Number.
  3. Add ordered TenureBand (0–1 yr, 2–4 yrs, 5–9 yrs, 10+ yrs) + TenureSort (1..4).
  4. Add Custom Column FlightRiskTier for Active Employees: 
    if [Attrition] = "Yes" then "Departed"
else if [OverTime] = "Yes" and [JobSatisfaction] = 1 and [WorkLifeBalance] = 1 then "1 - Critical Red Alert"
else if [OverTime] = "Yes" and ([JobSatisfaction] = 1 or [WorkLifeBalance] = 1 or [YearsSinceLastPromotion] >= 5) then "2 - High Risk"
else "3 - Normal"
  5. Click Home → Close & Apply.

Stage 3 & 4 — People-Analytics & Financial ROI DAX + What-If Parameter

Create Numeric Range What-If Parameter Replacement Cost % (`Min 0.30`, `Max 1.00`, `Increment 0.10`, `Default 0.50`). Then write:

Total Workforce = COUNTROWS ( 'Workforce' )
// Check: 220,000

Active Headcount =
CALCULATE ( [Total Workforce], 'Workforce'[Attrition] = "No" )
// Check: 173,526

Departed Headcount =
CALCULATE ( [Total Workforce], 'Workforce'[Attrition] = "Yes" )
// Check: 46,474

Attrition Rate % = DIVIDE ( [Departed Headcount], [Total Workforce] )
// Check: 21.12%

OverTime Share % =
DIVIDE (
    CALCULATE ( [Total Workforce], 'Workforce'[OverTime] = "Yes" ),
    [Total Workforce]
)
// Check: 21.95%

Avg Annual Salary = AVERAGE ( 'Workforce'[AnnualSalary] )
// Check: $104,371

Estimated Turnover Cost =
VAR Mult = 'Replacement Cost %'[Replacement Cost % Value]
VAR DepartedPayroll =
    CALCULATE ( SUM ( 'Workforce'[AnnualSalary] ), 'Workforce'[Attrition] = "Yes" )
RETURN
    DepartedPayroll * Mult
// Check at default 50% (0.50): $2,413,178,590 ($2.41B!)

Critical Flight-Risk Active =
CALCULATE (
    [Total Workforce],
    'Workforce'[FlightRiskTier] = "1 - Critical Red Alert"
)
// Check: Exactly 281 active employees!

8. Trainer's Troubleshooting: Common Beginner Mistakes

Mistake 1 — Deleting rows where TerminationDate is blank: Blank TerminationDate means the employee STILL WORKS HERE (`173,526` active staff)! Deleting blanks makes Attrition look like 100%!
Mistake 2 — Exposing Employee Names without Row-Level Security (RLS): Always protect compensation & employee PII with RLS roles before publishing HR reports to the Power BI Service!
