4. Phase A — Organize & Clean in Microsoft Excel

Goal: profile the workforce, build tenure/age/salary bins, compute risk flags, validate with a Pivot, then export a clean .xlsx.

Step 1 — Open correctly

Open the file: data/hr_workforce.csv, in the folder next to this guide (Excel auto-splits columns by comma). For full control of types use Data ▸ Get Data ▸ From Text/CSV → choose the file → set Delimiter = Comma → Load.
Set formats: HireDate, TerminationDate → Home ▸ Number ▸ Date; AnnualSalary, MonthlyIncome → Number; Attrition, OverTime, Gender → Text; scores/ages → Whole Number. Then View ▸ Freeze Panes ▸ Freeze Top Row.

Step 2 — Profile & find dirt

File is clean, but on a real client file: Data ▸ Filter → check Attrition="Yes" has a TerminationDate, and AnnualSalary < 30000 or blanks. Use Data ▸ Data Analysis ▸ Descriptive Statistics on AnnualSalary to see the skew (min $36,053, max $310,477, median $94,061).

Step 3 — Add helper columns (X–AB, after TerminationDate in W)

X TenureBucket   =IF(L2<=2,"0-2",IF(L2<=5,"3-5",IF(L2<=10,"6-10","11+")))
Y AgeBucket   =IF(F2<25,"<25",IF(F2<=34,"25-34",IF(F2<=44,"35-44",IF(F2<=54,"45-54","55+"))))
Z SalaryBand   =IF(O2<50000,"<50K",IF(O2<80000,"50-80K",IF(O2<120000,"80-120K","120K+")))
AA RiskFlag   =IF(AND(S2="Yes",Q2=1),"HIGH","OK")
AB IsAttrited   =IF(V2="Yes",1,0)
(Excel uses , as the argument separator, as shown. If your regional setting uses ;, swap commas for semicolons.) Fill down.

Step 4 — Validate with a PivotTable

Select data → Insert ▸ PivotTable. Rows = Department, Values = Average of AnnualSalary and Count of IsAttrited. Confirm Legal ~$127K, Operations ~$84K, and attrition ≈ 21% per dept (matches §1).

Step 5 — Format & export

AnnualSalary/MonthlyIncome → #,##0; rates → 0.0%. Save As hr_workforce_clean.xlsx — keep this as your working copy; Power BI reads the typed Excel file most reliably (better than the raw CSV).

5. Phase B — Build the Dashboard in Power BI

Step 1 — Get Data

Get Data ▸ Excel → hr_workforce_clean.xlsx → Load. (Or Text/CSV → comma → Transform → Load.)

Step 2 — Power Query

Transform Data: HireDate/TerminationDate = Date; AnnualSalary = Whole Number; Attrition/OverTime/Gender = Text; scores = Whole Number. Fix any mis-typed column, watch Applied Steps. Close & Apply.

Step 3 — Data Modeling

Single flat table here — fine for learning. Build a small Date table for hire trends:
HireCalendar = CALENDAR(DATE(2000,1,1), DATE(2024,12,31))
Relationship: HireCalendar[Date] → hr_workforce[HireDate].
Next level: split DimEmployee + FactAttrition + DimDepartment into a star schema.

Step 4 — DAX Measures

Headcount        = DISTINCTCOUNT(hr_workforce[EmployeeID])
Attrition Count  = CALCULATE(COUNTROWS(hr_workforce), hr_workforce[Attrition]="Yes")
Attrition Rate % = DIVIDE([Attrition Count], [Headcount])   -- ≈ 21.1%
Avg Salary       = AVERAGE(hr_workforce[AnnualSalary])
Avg Tenure       = AVERAGE(hr_workforce[YearsAtCompany])
Avg Satisfaction = AVERAGE(hr_workforce[JobSatisfaction])

OverTime Attrition % = CALCULATE([Attrition Rate %], hr_workforce[OverTime]="Yes")   -- 33.7%
NoOT Attrition %     = CALCULATE([Attrition Rate %], hr_workforce[OverTime]="No")     -- 17.6%

High Risk Count  = CALCULATE(COUNTROWS(hr_workforce),
                    hr_workforce[OverTime]="Yes", hr_workforce[JobSatisfaction]=1)   -- 5,848

Modeling ▸ New Parameter ▸ Numeric → Salary Raise % (0 to 0.20, step 0.01). Measure:

8. Trainer's Common Mistakes

  • Averaging Attrition Rate % across departments → wrong. Use DIVIDE(SUM attrited, SUM headcount) as a measure.
  • Storing Attrition Rate % as a column → totals break; always a measure with DIVIDE.
  • Salary histogram with too many tiny bins → use the SalaryBand helper for clean buckets.
  • Forgetting OverTime is text "Yes"/"No" → filter with quotes inside CALCULATE.
