4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Data → From Text/CSV → walmart-openings.csv. Set OPENDATE and date_super to Date.
Formats: OPENDATE → Date; conversion → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • Some OPENDATE values use a two-digit year, such as 10/1/74. If the year is after 2026, subtract 100. Use the OpenDateFixed helper.
  • Do not delete rows where date_super is blank.
  • type_store is the format (Wal-Mart, Supercenter).
  • LAT and LON are coordinates, not measures to sum.

Step 3 — Helper columns

Put these in the first empty columns and fill down (double-click the fill handle).
OpenDateFixed   =IF(YEAR(B2)>2026,DATE(YEAR(B2)-100,MONTH(B2),DAY(B2)),B2)
Excel on this machine uses a comma between arguments. If your Excel uses semicolons, swap them.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = STRSTATE. Put YEAR in Columns. Values = Sum of conversion. The grand total must be 1,557. If it is not, the filter or the number format is wrong — fix that before Power BI.
Use OpenDateFixed for the year chart. The date range in the sign-off is after that correction.

Step 5 — Save

Save As 04-walmart-openings-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Text/CSV. Set both date columns to Date. Blank date_super means 'not converted'.

Step 2 — Power Query

Rename the main query to Stores. Set the types from Step 1. Watch Applied Steps. Then Close & Apply. If OPENDATE has a year after 2026, subtract 100 years. Values such as 10/1/74 are 1974, not 2074.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

conversion = SUM('Stores'[conversion])
Row Count = COUNTROWS('Stores')
Filtered rows = CALCULATE([Row Count], 'Stores'[conversion] = <one of the two values>)

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis STRSTATE, value the main measure.
  • Line chart: axis OPENDATE.
  • A slicer for each small category (conversion, type_store, MONTH).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

6. Sign-off

  • ☐ Row count is 2,992 after the cleaning steps above.
  • ☐ Total conversion is 1,557.
  • ☐ The leading STRSTATE is TX at 200.
  • ☐ The date axis runs from 1962-07-01 to 2006-01-31.
  • ☐ Slicers filter every visual, and you can clear them back to the totals above.

7. Stretch

  • A map using STRSTATE or LAT/LON, with a slicer for type_store.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Counting conversions by averaging date_super.
  • Summing latitude.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
