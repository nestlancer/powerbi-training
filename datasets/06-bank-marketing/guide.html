4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

Step 1 — Open it the right way

Data → From Text/CSV → bank-full.csv. Set the delimiter to semicolon. A double-click will not split the columns.
Formats: balance → Number (2 decimals); pdays → Number; campaign → Number; previous → Number. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • This is the full file (about 45,000 calls), not the smaller bank.csv sample.
  • duration is how long the call lasted. It leaks the outcome — a model can cheat with it. For a dashboard it is fine to show, but say so.
  • pdays = -1 means the client was not contacted before. It is not a missing number.

Step 3 — Helper columns

Put these in the first empty columns and fill down (double-click the fill handle).
Subscribed   =IF(Q2="yes",1,0)
Excel on this machine uses a comma between arguments. If your Excel uses semicolons, swap them.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = job. Values = Average of Subscribed. The grand total must be 11.7%. Format the value as Percentage. If it is not, the filter or the number format is wrong — fix that before Power BI.

Step 5 — Save

Save As 06-bank-marketing-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Text/CSV → delimiter Semicolon.

Step 2 — Power Query

Rename the main query to Calls. Set the types from Step 1. Watch Applied Steps. Then Close & Apply.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

Subscription Rate =
DIVIDE(
    CALCULATE(COUNTROWS('Calls'), 'Calls'[y] = "yes"),
    [Row Count])
Row Count = COUNTROWS('Calls')

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis job, value the main measure.
  • A slicer for each small category (default, housing, loan).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

7. Stretch

  • Subscription rate = DIVIDE(CALCULATE(COUNTROWS(Calls), Calls[y]="yes"), [Row Count]).
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Averaging a yes/no column that you stored as text.
  • Treating pdays = -1 as 'contacted 1 day ago'.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
