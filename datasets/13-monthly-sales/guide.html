4. Phase A — Microsoft Excel

Goal: open the file cleanly, add only the helper columns you need, and prove one total with a PivotTable before you touch Power BI.

This set is a folder of files, not one sheet. In Excel, open one month and check it. In Power BI, use Get data → Folder and combine them. That is the point of this set.

Step 1 — Open it the right way

Excel: open Sales_January_2019.csv only, and delete any row where Order ID is the words 'Order ID'. Power BI: combine the whole data folder.
Formats: Order Date → Date. Then View → Freeze Panes → Freeze Top Row.

Step 2 — Look for dirt

  • Remove the repeated header rows (Order ID = 'Order ID').
  • Order Date should be a date/time. Take the month from it.
  • Purchase Address can be split into street, city, and state. City is the useful slicer.

Step 3 — Helper columns

Put these in the first empty columns and fill down (double-click the fill handle).
LineSales   =C2*D2
Year   =YEAR(E2)
MonthNum   =MONTH(E2)
MonthName   =TEXT(E2,"MMM")
Excel on this machine uses a comma between arguments. If your Excel uses semicolons, swap them.

Step 4 — Pivot check

Select the data → Insert → PivotTable. Rows = Product. Group the date by years and put years in Columns. Values = Sum of LineSales. The grand total must be $34.49M. If it is not, the filter or the number format is wrong — fix that before Power BI.
January file only, after you delete the repeated header row: LineSales grand total is $1,815,335. The sign-off number further down is the full year from all 12 files.

Step 5 — Save

Save As 13-monthly-sales-clean.xlsx. Power BI should read this file, not a half-filtered view you forgot to clear.

5. Phase B — Power BI

Step 1 — Get data

Get data → Folder → the data folder → Combine & Transform. Filter Order ID so it is not equal to Order ID, and remove blank Order ID rows. Then set Quantity Ordered and Price Each to decimal numbers.

Step 2 — Power Query

Rename the main query to Orders. Set the types from Step 1. Watch Applied Steps. Then Close & Apply.

Step 3 — Model

One table. A star schema is not required for this set.

Hide key columns you do not want on the report. A hidden column can still be used by a relationship.

Step 4 — Measures

Write these as measures, not calculated columns. Replace the placeholder filter with a real value from the column.

Line Sales = SUMX('Orders', 'Orders'[Quantity Ordered] * 'Orders'[Price Each])
Row Count = COUNTROWS('Orders')

Step 5 — Visuals

  • Cards for the measures in Step 4.
  • Bar chart: axis Product, value the main measure.
  • Line chart: axis Order Date.
  • A slicer for each small category (Quantity Ordered, Product, Price Each).
  • Click a bar and confirm the other visuals filter. Use Format → Edit interactions if one visual should stay still.

6. Sign-off

  • ☐ Row count is 185,950 after the cleaning steps above.
  • ☐ Total LineSales is $34.49M.
  • ☐ The leading Product is Macbook Pro Laptop at $8.04M.
  • ☐ The date axis runs from 2019-01-01 to 2020-01-01.
  • ☐ Slicers filter every visual, and you can clear them back to the totals above.

7. Stretch

  • Split Purchase Address and show revenue by city. A line of Line Sales by month for the full year.
  • Add a drill-through page that keeps the slicer filters and shows the underlying rows.
  • Sort a month-name column by the month number so the axis is not alphabetical.

8. Mistakes that hide the answer

  • Loading one month and comparing it to the full-year total in this guide.
  • Leaving Quantity as text, so Sum becomes Count.
  • Summing an ID column, or averaging a rate that was already a percent.
  • Leaving dates as text, then wondering why the axis sorts wrong.
